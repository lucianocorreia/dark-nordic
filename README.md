# Dark Nordic

Dark Nordic is a dark-only Visual Studio Code theme inspired by the Nordic palette.

## Palette

| Role | Color |
| --- | --- |
| Background | `#242933` |
| Surface | `#1E232D` |
| Foreground | `#ECEFF4` |
| Red | `#F48771` |
| Orange | `#D08770` |
| Yellow | `#EBCB8B` |
| Green | `#A3BE8C` |
| Cyan | `#88C0D0` |
| Blue | `#81A1C1` |
| Purple | `#B48EAD` |

## Use

Install the extension, then choose **Dark Nordic** from the Color Theme picker in Visual Studio Code.
